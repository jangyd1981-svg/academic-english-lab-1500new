# Academic English Lab 1500 · 6.0.0

1,500개 어휘를 내장한 반응형 플래시카드 PWA입니다.

## 시작
1. 이전 앱의 JSON 학습 기록과 GitHub 저장소를 먼저 백업합니다.
2. 이 ZIP의 파일을 압축 해제한 뒤 기존 GitHub Pages 저장소의 최상위에 업로드합니다.
3. index.html이 최상위에 있는지 확인하고 커밋합니다. 기존 Pages main / (root) 설정을 유지합니다.
4. 배포 성공 후 Safari에서 사이트를 열고 홈 화면에 추가합니다.
5. 진도·설정에서 이전 버전을 선택해 기록을 가져옵니다.

자세한 안내는 guide.html, 검수 범위는 review.html을 열어 확인하세요.
이 파일 자체를 파일 앱에서 미리보기하는 것은 PWA 설치가 아닙니다.

## 기능
하루 신규 최대 15개 · 중복 없는 날짜별 배정 · 플래시카드 · 4지선다 퀴즈
IPA/뜻/예문/해석 · 단어 및 예문 TTS · 간격 복습 · 오답 목록 · 미학습 목록
분야별 검색 · 학습 진도 · 기기 내 저장 · JSON 백업/합치기 · 지원 이전 버전 가져오기
온라인 최초 접속 및 캐시 준비 후 오프라인 학습 · 캘린더용 오전8시 일정 내보내기

## 제한
서버 푸시, 로그인, 자동 기기 간 동기화, App Store 배포는 포함하지 않습니다.
발음은 녹음 파일이 아니라 기기 TTS와 별도 IPA입니다.
예문은 실제 사건 인용이 아닌 학습용 작성문입니다.
1,500개 전부 의미의 외부 사전 개별 대조/독립 전문가 감수/아이폰 실기기 검증을 했다고 주장하지 않습니다.
발음 출처 유형 및 실제 검수·기능 테스트 결과는 review.html, DATA_AUDIT.json, TEST_REPORT.json에 있습니다.
브라우저 화면은 정적 파일을 메모리에 로드해 검사했고 저장 어댑터를 사용했습니다. 실제 HTTP 서비스워커 설치와 네이티브 저장소 장기 유지 검사는 하지 못했으며, 캐시 동작은 별도 모의 검사입니다.
개인 학습 기록 백업 JSON은 공개 GitHub 저장소에 올리지 마세요.
