ACADEMIC ENGLISH LAB / 1500 EDITION

설치와 이용 안내

기존 GitHub Pages와 아이폰 홈 화면에서 이어서 사용하세요.

1. 기존 기록부터 백업하세요

기존 앱의 JSON 백업을 저장합니다. 기존 저장소도 GitHub의 Code → Download ZIP으로 보관하세요. 새 앱이 기존 기록을 자동으로 이어받는다고 가정하지 마세요.

이 버전은 새 저장 키를 사용하며, 기존 ael_learned와 ael_review를 삭제하지 않습니다. 앱의 진도·설정에서 이전 버전을 선택한 후 가져옵니다. 이전 단어 번호를 새 단어 번호에 단순 연결하지 않습니다.

2. GitHub Pages에 업로드

  1. 받은 ZIP을 아이폰의 파일 앱 또는 PC에서 압축 해제합니다.
  2. 기존 GitHub 저장소 Code 화면에서 Add file → Upload files를 선택합니다. 작은 화면에서는 메뉴가 접혀 있을 수 있습니다.
  3. 압축이 풀린 폴더 안의 파일을 올립니다. ZIP 파일 자체나 상위 폴더를 하나 더 올리는 것이 아닙니다. index.html이 기존처럼 저장소 최상위에 있어야 합니다.
  4. 같은 이름의 파일은 새 파일로 교체하고 Commit changes를 누릅니다. 기존 CNAME을 쓰는 사이트라면 그 파일은 보존합니다.
  5. Settings → Pages에서 기존 배포 설정 Deploy from a branch / main / (root)를 유지합니다. 실제 저장소가 다른 브랜치로 운영되고 있다면 기존 설정에 맞춥니다.
  6. GitHub의 배포 작업이 성공했는지 확인한 다음 Visit site로 접속합니다. 화면 위에 1500 EDITION, 진도·설정 아래에 6.0이 표시되는지 확인합니다.

파일을 올릴 수 있는 것은 앱 코드와 공개 어휘 데이터입니다. 개인 학습 기록 백업 JSON은 공개 저장소에 업로드하지 마세요.

아직 기존 파일이 보이면 온라인 상태에서 사이트를 다시 열고 새로고침합니다. 새 버전 알림이 보이면 업데이트를 누릅니다. 기존 홈 화면 앱도 완전히 닫았다 다시 엽니다. 캐시 문제를 해결하려고 사이트 데이터를 삭제하기 전에는 반드시 기록을 백업하세요.

3. 아이폰 홈 화면에 추가

Safari에서 배포된 HTTPS 사이트를 엽니다. 공유 메뉴 → 홈 화면에 추가 → 웹 앱으로 열기가 있으면 켜기 → 추가를 선택합니다. iOS 버전에 따라 메뉴 위치가 다를 수 있습니다. 파일 앱의 HTML 미리보기 화면이 아니라 Safari의 실제 사이트에서 진행하세요.

기존과 같은 주소를 덮어쓴 경우 홈 화면 아이콘을 꼭 새로 만들 필요는 없습니다. 화면과 기록을 확인한 뒤 필요할 때 새로 추가합니다.

4. 기록 옮기기

진도·설정 → 이전 앱 기록 가져오기에서 실제 사용했던 버전을 선택합니다. 70개 시작판, 1차 200개 검수판, 기존 1,000개 초안의 번호-단어 대응표가 내장되어 있습니다.

이전 JSON 백업을 선택하거나 같은 브라우저에서 ‘이 브라우저의 이전 기록’을 누릅니다. 일치한 단어 수와 건너뛴 수를 확인한 후 합칩니다. 이번 단어장에 없는 단어, 잘못 생성된 옛 단어, 지원하지 않는 버전의 기록은 안전하게 연결할 수 없습니다. 156개판 등 다른 목록은 직접 지원하지 않습니다.

새 버전끼리는 JSON 백업 저장 → 백업 불러오기를 사용합니다. 복원은 현재 기록과 합치며, 같은 단어의 횟수를 더해서 부풀리지 않습니다. Safari와 홈 화면 웹 앱의 저장 공간이 항상 같다고 가정하지 말고 필요 시 백업 파일로 옮기세요.

하루 15개는 어떻게 바뀌나요?

한국 날짜가 바뀐 뒤 앱을 열면 아직 배정하지 않은 어휘를 최대 15개 고릅니다. 이미 배정한 단어를 신규 단어로 다시 배정하지 않습니다. 날짜마다 무작위 구간을 추출하는 방식이 아닙니다. 여러 분야가 섞이도록 순서를 구성했습니다.

앱을 열지 않은 날에는 진도가 강제로 진행되지 않습니다. 1,500개를 모두 신규로 배정하는 데는 앱을 여는 학습일 100일이 필요합니다. 단어장에서 미리 학습한 항목은 다음 신규 배정에서 제외하므로 이 경우 신규 배정 일수는 줄어들 수 있습니다. 배정과 실제 학습 완료는 별개입니다. 놓친 단어는 ‘배정 후 미학습’에서 찾습니다.

오답은 자동으로 저장됩니다. 카드 평가 ‘기억나요’와 ‘아주 쉬워요’는 다음 복습 날짜를 정합니다. ‘다시 공부’는 오늘 복습 목록에 남깁니다. 3일 이상 서로 다른 날에 성공적으로 회상한 어휘는 별도 진도로 표시합니다.

오프라인·저장·알림의 범위

오프라인: 온라인으로 처음 접속해 캐시 설치를 마친 뒤 앱을 다시 열면 단어장·퀴즈·복습을 사용할 수 있습니다. 외부 사전 링크와 OS 음성 다운로드는 인터넷이 필요할 수 있습니다. 사이트 데이터 삭제나 운영체제의 저장소 정리로 캐시가 사라질 수 있습니다.

저장: 계정이나 클라우드 서버 없이 이 기기의 브라우저에 기록을 저장합니다. 브라우저 삭제·시크릿 모드 종료·기기 변경·사이트 주소 변경 시 기록이 유지되지 않을 수 있으므로 JSON 백업이 필요합니다. 데이터 삭제를 실행하기 전에는 항상 백업하세요.

발음 듣기: 기기의 영어 TTS를 사용합니다. 녹음 파일 1,500개를 내장한 것이 아니며, 기기 음성과 IPA의 세부 발음이 완전히 일치한다고 보장하지 않습니다.

알림: 앱이 닫혀 있어도 전달되는 서버 푸시는 구현하지 않았습니다. 아이폰 미리 알림에서 매일 오전 8시를 설정하는 방식이 가장 단순합니다. 제공한 ICS 일정 파일은 캘린더에 가져온 후 알림을 허용해야 합니다. 같은 일정을 여러 번 등록하면 중복 알림이 생길 수 있습니다.

서버 갱신: 1,500개는 앱에 내장되어 있으며 매일 인터넷에서 새 어휘를 받아오지 않습니다. 비용·가입·API 키 없이 작동합니다.
